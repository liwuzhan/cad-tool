# CAD Tool Privacy Policy

Effective date: 2026-08-27

The CAD Tool Codex plugin is a local, skills-only plugin. It does not operate a
remote service, collect personal information, use analytics, or transmit model
files to the plugin author.

When a user approves environment setup, the installer invokes Python package
management to download declared open-source dependencies from the package
index configured on that machine. Codex and the user's execution environment
may separately process prompts, files, and command output under their own
settings and policies.

Questions and privacy reports can be filed at
https://github.com/liwuzhan/cad-tool/issues.
