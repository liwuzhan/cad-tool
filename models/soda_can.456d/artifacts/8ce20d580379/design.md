# 罐装可乐易拉罐（330ml 经典款）

## 零件描述
标准 330ml 罐装可乐易拉罐的外形实体模型：
- 圆柱罐体（直径 66mm）+ 底部内凹圆顶（dome）+ 顶部锥形收口肩部 + 罐口颈段
- 顶盖内凹，中央带 rivet 铆钉与椭圆拉环（pull tab）
- 采用旋转体（revolve）建模罐体，保证旋转对称与曲面光滑

## 关键尺寸表

| 符号 | 数值 (mm) | 说明 |
|------|-----------|------|
| can_radius | 33 | 罐体外半径（直径 66） |
| can_height | ~115 | 罐体总高（顶盖边沿 114 + 拉环突出） |
| dome_apex_z | 8 | 罐底内凹圆顶顶点高度 |
| dome_flat_r | 4 | dome 顶部平顶半径（OCC 约束：锥面不得在旋转轴上收尖，否则非流形） |
| dome_edge_z | 2 | 罐底外沿接触面高度（内凹深度 6mm） |
| z_taper_start | 92 | 肩部锥形收口起始高度 |
| z_neck_top | 114 | 罐口颈段顶部（顶盖边沿） |
| neck_radius | 27 | 罐口半径（收口后） |
| lid_center_z | 113 | 顶盖内凹中央高度（内凹 1mm） |
| lid_inner_r | 23 | 顶盖内凹斜面内边界半径 |
| tab_z_base | 112.8 | 拉环底面（埋入顶盖 0.2mm 保证布尔合并） |
| tab_thickness | 1.5 | 拉环厚度 |
| tab_outer / tab_inner | 9 × 4.2 / 6.4 × 2.4 | 拉环外/内椭圆（半轴） |
| rivet_r / rivet_h | 1.7 / 1.9 | 中央铆钉半径/高度 |

**总尺寸**：X = Y = 66mm，Z = 113.3mm（Z 从 2mm 底沿到 115.3mm 铆钉顶）
**目标体积**：≈ 360,479 mm³（cad_run 实测外轮廓体积；内容量对应 330ml 级别）

## 建模策略

1. **基体（revolve）**：在 `Plane.XZ` 画右半边截面轮廓（X 为半径方向，Z 为高度），绕 Z 轴旋转 360°：
   - 底部 dome 弧：`(0,8) → (4,8) → (12,3.6) → (22,2.4) → (33,2)`（平顶+折线近似内凹圆顶；平顶保证锥面不接触旋转轴）
   - 直壁：`(33,2) → (33,92)`
   - 肩部收口：`(33,92) → (30,98) → (27,106)`（折线近似圆弧过渡）
   - 罐口颈段：`(27,106) → (27,114)`
   - 顶盖内凹：`(27,114) → (23,113) → (0,113)`，沿 Z 轴闭合
2. **拉环特征（extrude ADD）**：在 `Plane.XY.offset(tab_z_base)` 画椭圆环（外椭圆减内椭圆）+ rivet 圆，向上挤出；底面埋入顶盖 0.2mm 确保与罐体布尔合并为单一实体
3. **铆钉突出（Cylinder ADD）**：rivet 位置再加一个小圆柱，形成铆钉凸起

## 约束校验项
- 每步 `expect_solids(1)`：布尔后始终单一实体（拉环埋入顶盖，不得分离成多实体）
- 基体 Checkpoint：`expect_bbox_size(66, 66, 112, tolerance=1)`（Z: 2→114）
- 体积锚定：罐体 revolve 后体积实测 360,774 mm³（Checkpoint tolerance=300）
- 拉环 ADD 后体积必须增加（`expect_volume_increased`）
- 顶盖/底部内凹方向正确：底面最低点在 z=2（外沿），dome 顶点 z=8（向罐内凹）
