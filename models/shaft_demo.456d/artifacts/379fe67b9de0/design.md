# Declarative stepped shaft (bearing-sized seats) - 设计文档

## 零件描述

两根深沟球轴承支撑的阶梯轴，中间用隔套定距，一端输出轴伸。**本包的重点不是这根轴
本身，而是它的尺寸来源**：轴颈直径与长度全部由「哪个轴承装在哪个工位上」推导，脚本
里不出现任何轴颈直径字面量。

验证目标：改 `BEARING_CODE`，整根轴（直径、长度、轴向链、轴肩位置）自动跟随，且
轴颈接口与轴承接口的配对判定仍然成立。

## 关键尺寸

轴颈尺寸**不在本表**——它们由下表的关系推出，不是设计者给定的。

| 参数 | 值 | 来源/备注 |
|------|------|-----------|
| `BEARING_CODE` | `6204` | 两端支撑轴承型号，唯一的规格决策 |
| 轴颈 ⌀ / 长度（support_a/b） | ⌀20 × 14 | **由轴承 `shaft_bore` 接口推导**（6204 → bore 20, width 14） |
| 隔套外径 / 长度 | ⌀26 × 22 | 自由段，显式给（无库件可依据） |
| 输出轴伸 ⌀ / 长度 | ⌀16 × 30 | 自由段，显式给 |
| 总长 (Z) | 80 | 各段累加：14 + 22 + 14 + 30 |
| 最大外径 (X/Y) | 26 | 隔套处 |

换成 `6205` 后（对照）：轴颈 ⌀25 × 15，总长 82，最大外径仍 26。

## 建模策略

1. 声明**装配关系**（`ShaftSpec` 的工位列表）：
   `Seat` 引用库件 + 接口 → 该段尺寸由它决定；`Free` 为无库件依据的自由段。
2. 解析：`shaft_dimensions()` 读每个 `Seat` 所引用库件的接口，取直径/长度，累加轴向链。
3. 生成：`stepped_shaft()` 把工位列表合成一条半剖轮廓，绕 Z 轴**回转**成单一实体
   （不是布尔堆叠，所以轴肩是真实端面）。
4. 发射接口：每段座位/轴颈 → `cylindrical_surface`；每个直径突变 → `planar_face` 轴肩；
   两端 → `shaft_end`；另加 `rotation_axis`。

## 约束校验项

| 项 | 手段 | 类别 |
|----|------|------|
| 单一实体、包围盒 = 轴向链 | `Checkpoint.expect_solids/expect_bbox_size` | 自洽性（模型检查自己） |
| **轴颈接口 ≡ 所声明轴承接口** | 两个独立来源比对：轴的发射接口 vs 轴承 `shaft_bore` | **外部真值（模型改不了）** |

两类断言的可信度不同：自洽性断言在模型算错时会跟着一起错；外部真值断言有两个独立
来源，任一侧改了而另一侧没跟上就会失败。**这个区别是后续检查器（P3）的设计前提。**

## 明确不做

- **不建模配合公差**：`diameter_delta` 是调用者显式给的余量，发射的 `nominal_diameter`
  恒为名义值。没有 H7/k6 之类的配合推断。
- 不建模键槽、挡圈槽、倒角、圆角、螺纹、材料与热处理。
- 不做强度/寿命/临界转速——本包不含仿真，这类指标落在验证边界之外。
