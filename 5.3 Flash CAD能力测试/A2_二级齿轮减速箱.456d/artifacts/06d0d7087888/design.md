# A2 二级齿轮减速箱 - 装配设计文档

## 装配目标
单级箱体式二级圆柱齿轮减速机（展开式）：输入轴 → 中间轴 → 输出轴，总传动比
i = (43/17)·(51/19) ≈ 6.78。箱体为非标铸造壳体（轴承孔位于前后墙），顶部盖板 +
6× M6 螺栓，底部 4 地脚 + 放油塞。总 26 个实例，考察大规模装配布局、标准件复用、
齿轮啮合中心距计算与轴系布置。

## 坐标与接口

- 世界坐标：X 长、Y 宽、Z 高；齿轮箱三根轴沿 **X** 方向，轴心 YZ 位置如下。
- 齿轮副中心距（module=1.5）：a1 = 1.5·(17+43)/2 = **45**（I–M，沿 +Y）；
  a2 = 1.5·(19+51)/2 = **52.5**（M–O，沿 −Z）。
- 轴心：I=(y15, z100)，M=(y60, z100)，O=(y60, z47.5)。
- 啮合相位：大齿轮绕轴转半齿距角（180/z），避免齿对齿硬顶（占位级近似，非精确啮合）。
- 齿轮/键与轴的键槽配合按目录声明为名义干涉（keyway omitted），是合法占位配合。
