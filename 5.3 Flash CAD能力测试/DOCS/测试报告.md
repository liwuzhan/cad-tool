## 二、能力边界评估

### 做得好的
- **参数化驱动**：所有尺寸命名变量化，凸轮廓线由运动规律函数生成（非手工描点）
- **数值断言兜底**：Checkpoint 体积/bbox/实体数断言在 P1/P2/P4/A1/A2 上全部与解析解吻合
- **多模态审查闭环**：渲染读图→发现减重孔打穿轮缘（P2）、臂端侵占法兰面（P4）等问题并修正
- **标准件生态**：cadparts 渐进式查询（search→describe→instantiate）+ 采购语义 + 接口坐标，26 实例装配无返工
- **中文路径/包名**：全流程（init/run/review/commit/export）未因中文文件名出错

### 能力极限（当前边界）
1. **抽壳类模型的体积断言不可信**：offset 抽壳 BRep 体积积分虚高 ~20%，且后续布尔运算放大误差
   （P3 被迫改用 solids/bbox/faces 断言 + STL 网格离线复核）。这是内核层问题，非模型层可修复。
2. **复合边线倒圆易失败**：曲面与曲面相交的边线（如法兰顶缘被臂截断）倒圆对半径敏感，需要降级重试策略。
3. **变截面放样的内腔抽壳**：手工内腔放样在拱顶区会"抢料"削掉外壳顶（P3 教训），法向等距壳仍只能依赖 offset。
4. **装配无干涉检查**：键/轮毂名义干涉、螺栓过孔等靠目录声明+人工视觉判断，无自动豁免表。

## 四、给插件的改进建议

1. `docs/build123d_skills.md` 与 0.11.1 实际 API 对齐（#1 #2 #3 #7 一次全修）
2. Checkpoint 增加可选 `mesh_volume` 校验模式，绕开 GProp 对 offset/BSpline 曲面的积分误差
3. offset 失败错误信息列出已尝试的 Kind；loft 文档加"可抽壳截面"指引
4. Locations 嵌套规则写入文档；落点全空材料时给警告
5. 装配级干涉检查（带豁免表）是当前装配工作流最大的缺口
