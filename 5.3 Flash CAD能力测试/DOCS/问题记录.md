- **[通用] 严重度：中｜状态：已确认** `docs/build123d_skills.md` 文档 API 名过时：选择器过滤器写作 `GeType.LINE`，build123d 0.11.1 中实际为 `GeomType.LINE`（`GeType` 未导出，直接 NameError）。建议批量更新文档。


- **[P2] 严重度：中｜状态：已确认** `Rotation` 不能像旧版教程那样作 with 上下文管理器（`with Rotation(90,0,0):` 报 `'Rotation' object does not support the context manager protocol`）。正确用法是 `Locations(Pos(...) * Rotation(90,0,0)):` 相乘组合后进入 `Locations`。建议 `build123d_skills.md` 增补该模式。
- **[P2] 严重度：低｜状态：已绕过**（模型侧教训，非插件 bug）凸轮非圆轮廓上布置径向特征时，不能按基圆半径留边——摆线升程起点附近实际半径≈基圆，Ø9@R15.5 减重孔在 45°/315° 打穿轮缘。修正为 Ø7@R11.5。教训：非对称轮廓上打孔前应先按角度计算局部半径验证 reach。

- **[P3] 严重度：中｜状态：已确认** `docs/build123d_skills.md` 1.2 节草图中 `RoundedRectangle` 同样不存在，build123d 0.11.1 实际类名为 `RectangleRounded`。与 GeType 同属文档 API 名未与 0.11.1 对齐的问题。

- **[P3] 严重度：高｜状态：已确认（已绕过）** 多截面 `loft`（各层 `RectangleRounded` 圆角矩形、圆角半径逐层变化）生成的侧曲面为 BSpline，`offset(amount, openings=底面)` 抽壳对任何 `Kind` 均报 `offset Error, an alternative kind may resolve this error`（实测 ARC/INTERSECTION 全失败，TANGENT 直接不支持）。**绕过**：改用椭圆截面放样（无角点扭转问题），抽壳 0.3s 成功。建议：① 文档加"可抽壳放样"指引；② 错误信息可附 Kind 已尝试列表。此问题对"美观壳体类"建模是硬阻塞点。

- **[P3] 严重度：高｜状态：已确认（已绕过）** `offset(amount<0, openings=...)` 抽壳得到的 BRep **体积/面积积分失真**：BRep 报 22,934 mm³，STL 网格积分真值 19,036 mm³（虚高 ~20%）；`is_valid()` 仍为 True。后续在其上做布尔（切滚轮槽）后 BRep 甚至报出**体积增加**的荒谬值（-切材料反而 +1563），而 `result - shell` 布尔差集体积为 0 证明材料确实只减不增。**对 Checkpoint 的影响**：`expect_volume`/`expect_volume_decreased` 在抽壳类模型上会被内核骗过/误报。**绕过**：抽壳后的特征只断言 `expect_solids/expect_bbox_size/expect_faces`，真实体积用 `export_stl + 网格积分` 离线复核。建议：① 排查 OCC GProp 对 offset 曲面的积分；② Checkpoint 可选 mesh-volume 校验模式。
- **[P3] 严重度：低｜状态：已绕过** 手工"内腔放样减法抽壳"方案中，内腔顶部封小截面（为高出外顶干净减）会按锥度放大内腔在拱顶区的占位，把外壳拱顶削掉（bbox z 35.5→28.7）。教训：变截面放样内腔不能简单"顶上再加一节"，需按法向偏距逐截面计算。
- **[P3] 严重度：低｜状态：已确认** `Checkpoint.expect_faces(n)` 不接受 `tolerance` 关键字参数（文档未提，报 TypeError）。face 数断言本身可用。

- **[P4] 严重度：高｜状态：已确认（已绕过）** `Locations` 与 `PolarLocations` **嵌套语义反直觉**：`with PolarLocations(...): with Locations((x,y)):` 组合时，位置合成结果既不是"绕 (x,y) 的极位阵列"也不是简单的 (x,y)，打孔全部落空（体积 Δ=0，且 Checkpoint 差一点被 Δ=0 的"通过"漏掉——好在 expect_volume_decreased 拦住了）。**正确写法**：`with Locations((x,y)):` 在外、`with PolarLocations(...):` 在内，实测 4×π·1.7²·4=145.27 mm³ 与解析完全吻合。建议：① 文档补充嵌套规则；② Locations 嵌套时若最终落点为空材料可给出警告。
- **[P4] 严重度：低｜状态：已绕过** 复合边线（圆弧被曲面截断）上 `fillet(r=2.0)` 报错提示用 `max_fillet()`；脚本用 try/except 降级 2.0→1.0→跳过处理。错误信息本身有帮助。
- **[P4] 严重度：低｜状态：已绕过**（模型侧教训）被臂料侵入的法兰顶面，其 `face.center()` 会偏离几何圆心，按"圆心+高度"选面会 IndexError；改为"按高度过滤 + 按面积取最大"更鲁棒。
