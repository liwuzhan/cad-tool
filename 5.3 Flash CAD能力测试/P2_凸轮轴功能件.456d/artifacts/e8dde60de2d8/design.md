# P2 凸轮轴功能件 - 设计文档

## 零件描述
摆动从动件平面凸轮（一体轮毂式）：基圆 Ø36、升程 14mm 的心形凸轮廓线（摆线运动规律：
升程-远休-回程-近休），轮毂贯穿 8mm 孔 + DIN 6885 键槽，径向 M5 顶丝孔，盘面 4× Ø9
减重孔。考察：参数化轮廓曲线、非对称轮廓布尔、径向孔、键槽位置语义。

## 关键尺寸

| 参数 | 值 (mm) | 来源/备注 |
|------|------|-----------|
| 总长 (X) | 64 | 凸轮最大直径 Ø64（基圆 Ø36 + 升程 2×14） |
| 总宽 (Y) | 64 | 同上 |
| 总高 (Z) | 32 | 轮毂 z -10..22，凸轮盘 z 0..12 |
| 基圆半径 | 18 | r_base |
| 升程 | 14 | h，最大半径 32 |
| 运动规律 | 摆线 | 升 0..150°，远休 150..200°，回 200..310°，近休 310..360° |
| 凸轮盘厚 | 12 | z 0..12 |
| 轮毂 | Ø26 × z -10..22 | r=13 |
| 孔 | Ø8 贯穿 | r=4 |
| 键槽 | 宽 3.4，孔壁深 1.3 | DIN 6885 Ø8 轴用键 3×3，+Y 方向 |
| 顶丝孔 | Ø5.2 径向 | -Y 侧，z=6，深约 9 |
| 减重孔 | 4× Ø7 | 分布圆 R11.5，45/135/225/315°（修：原 Ø9@R15.5 在 45°/315° 打穿轮缘）|

## 建模策略
1. 参数化生成 181 点凸轮廓线（摆线升回程）→ Polygon 面化 → 挤出 12
2. 轮毂圆柱挤出（与盘融合）
3. 孔+键槽一次草图（Circle + Rectangle SUBTRACT）贯穿
4. 4× 减重孔贯穿（在轮毂半径之外，只切盘）
5. 径向顶丝孔（旋转圆柱 SUBTRACT）

## 约束校验
- [x] 每特征 expect_solids(1)
- [x] 盘外接 64×64，总高 32
- [x] 减材特征后 expect_volume_decreased
