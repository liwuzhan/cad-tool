# P1 六角垫块 - 设计文档

## 零件描述
六角立柱式垫块，顶端带中心通孔与沉孔、3× 极定位安装孔，用于设备螺栓连接与定位。
入门级几何体测试：基本草图/挤出、极定位孔阵列、沉孔、外缘倒角。

## 关键尺寸

| 参数 | 值 (mm) | 来源/备注 |
|------|------|-----------|
| 总长 (X) | 46.19 | 六角外接圆直径 2R，R=across_flats/√3 |
| 总宽 (Y) | 40 | 对边距 across_flats |
| 总高 (Z) | 20 | height |
| 中心通孔 | Ø10.5 | center_hole_r=5.25，M10 过孔 |
| 沉孔 | Ø16 × 5 深 | 顶面 |
| 安装孔 | 3× Ø6.5 通孔 | 分布圆 R15，120° 均布 |
| 倒角 | 1.5 | 顶面外缘 |

## 建模策略
1. 六边形草图（RegularPolygon 外接圆 R23.094）→ 挤出 20
2. 中心通孔 → 顶部沉孔
3. PolarLocations 3× 安装通孔
4. 顶面外缘 6 条直线边倒角 1.5（按 GeType.LINE 过滤避开孔缘）

## 约束校验
- [x] 基体：expect_solids(1), expect_bbox_size(46.19, 40, 20), 体积=六角面积×20
- [x] 每次减材后 expect_volume_decreased
- [x] 最终体积 ≈ 23260 mm³（沉孔-572、安装孔-99.5、中心孔-86.6、倒角-156）
