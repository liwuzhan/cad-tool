## 流程约定（每个模型）

1. design.md 写尺寸表与建模策略
2. src/main.py 参数化建模 + Checkpoint 数值断言
3. cad_run 执行 → cad_review 视觉审查（多模态读图）
4. cad_commit 固化版本 → cad_export 导出 STEP
