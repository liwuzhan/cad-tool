# P3 人体工学鼠标外壳 - 设计文档

## 零件描述
右手人体工学无线鼠标上壳（美观曲面件）：多截面放样生成的拱背曲面实体，底部开口
抽壳 1.8mm 壁厚，前部滚轮槽。考察：多截面 loft 曲面连续性、shell/offset 开口面选择、
穿透曲面的减材特征、美观比例。

## 关键尺寸

| 参数 | 值 (mm) | 来源/备注 |
|------|------|-----------|
| 总长 (Y) | 115 | 鼠标纵向（前端 +Y） |
| 总宽 (X) | 63 | 最大截面在 z=8 |
| 总高 (Z) | 35.5 | 拱顶 |
| 壁厚 | 1.8 | 底面开口 shell |
| 滚轮槽 | 椭圆 Ø6×26 | 中心 y=+22，竖直贯穿拱面 |

## 放样截面表（椭圆 z, 宽W, 长L）

| z | W×L 椭圆 |
|---|-------|
| 0 | 62×115 |
| 8 | 63×112 |
| 18 | 60×100 |
| 26 | 52×80 |
| 32 | 38×54 |

（原方案圆角矩形放样无法抽壳，改椭圆截面，见 DOCS/问题记录.md）

## 建模策略
1. 6 个不同高度平面上的圆角矩形草图 → loft 成拱背实体
2. offset(-1.8, openings=底面) 抽壳成开口壳体
3. 前部椭圆滚轮槽从 z=40 向下贯穿（深度 26）

## 约束校验
- [x] 放样后 expect_solids(1), bbox(63, 115, 35.5)（普通放样体积积分可靠）
- [x] 抽壳/切槽后：体积积分失真（offset BRep 虚高 ~20%），改断言 solids/bbox/faces
- [x] STL 网格复核真实体积 ≈ 19,214 mm³（BRep 报 23,609 为内核积分误差）

## 最终建模策略（实测修订）
椭圆 6 截面放样 → offset(-1.8, openings=底面) 抽壳 → y=22 滚轮椭圆槽贯穿。
手工内腔放样方案会削掉拱顶（内腔在顶部抢料），已放弃；offset 几何正确可用。
