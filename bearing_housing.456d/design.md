# 轴承座 - 设计文档

## 零件描述
L型轴承座，由垂直前板和水平底座组成。前板中心有Φ42mm轴承孔，底座四角有4个Φ6.5mm安装孔。板厚2mm。

## 关键尺寸

| 参数 | 值 | 来源/备注 |
|------|------|-----------|
| 前板长度 (X) | 76 | 主视图宽度 |
| 前板高度 (Z) | 51.5 | 主视图高度 |
| 底座长度 (X) | 54 | 俯视图长度 |
| 底座宽度 (Y) | 40 | 俯视图宽度 |
| 板厚度 | 2 | 薄板厚度 |
| 中心孔直径 | 42 | Φ42 |
| 安装孔直径 | 6.5 | 4×Φ6.5 完全贯穿 |

## 建模策略
1. 创建垂直前板 (76×2×51.5)
2. 创建水平底座 (54×40×2)，与前板底部连接
3. 挖中心Φ42孔
4. 打4个Φ6.5安装孔
